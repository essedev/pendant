- Docs are in English. `README.it.md` is the Italian mirror of `README.md`, updated in the
  same commit, with real Italian accents, never an apostrophe in place of an accent.
- No em dash and no emoji: plain hyphens, commas or periods.
- Docs and code change in the same commit, so the docs do not fall behind.
- Prices, measurements and Omi app behaviour carry source and date: without a date they cannot
  be verified.
- New choices go in `DECISIONS.md` with date and reason.
- `docs/archive/` is read, never updated.
